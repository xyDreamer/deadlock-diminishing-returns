# Deadlock Stacking

Калькулятор для Deadlock: показывает, сколько процентов на самом деле дают несколько предметов вместе. Большинство процентов в игре не складываются, а считаются по убыванию, поэтому 35 % и 35 % антихила дают 57,8 %, а не 70 %.

Всё приложение — один файл [Deadlock-Stacking.html](Deadlock-Stacking.html). Откройте его в браузере. Работает и без интернета, только шрифты будут системные.

## Что внутри

- 11 статов: антихил, лайфстил, Bullet / Spirit / Melee Resist и шред, Damage Reduction, замедление, скорость стрельбы, кулдауны и длительность контроля.
- Предметы разбиты на Weapon, Spirit и Vitality, их можно сортировать по проценту и цене. Под каждым видно, сколько он добавит к уже выбранным.
- Способности героев с уровнями прокачки и поиском по героям.
- Карточка предмета или способности при наведении, как на вики. На телефоне — долгим нажатием.
- Учитываются стаки (Spirit Rend, Escalating Resilience, Spellslinger), активные эффекты и улучшения: если выбрать Crippling Headshot, Weakening Headshot уйдёт из сборки.
- График показывает, как растёт итог с каждой покупкой. Порядок покупок меняется перетаскиванием.
- Под графиком формула и расчёт по шагам для текущей сборки.

Выбор сохраняется в браузере.

## Данные

Цифры, иконки и карточки взяты с [Deadlock Wiki](https://deadlock.wiki), актуально на 28.10.2026. Valve часто меняет баланс, так что после патча данные стоит обновить. Нужен Python 3 и две библиотеки:

```
python -m pip install pillow beautifulsoup4
```

Если `python` не находится, вместо него пишите `py`. Затем запустите скрипты:

```
python tools/build_abilities.py
python tools/build_cards.py
python tools/build_icons.py
```

Скрипты вписывают данные прямо в HTML. Скачанное они хранят в `tools/.icon-cache/`; чтобы забрать с вики свежие версии, удалите эту папку перед запуском. Проценты предметов в списках правятся вручную в массиве `CATS`.
